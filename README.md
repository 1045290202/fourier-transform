# 傅里叶变换可视化（fourier-transform）

用 Cocos Creator 演示傅里叶级数的可视化项目：把一串首尾相接、各自旋转的圆（epicycle / 本轮均轮）末端当作画笔，笔尖走过的轨迹就是这些圆叠加合成的波形；反过来，一个复杂信号也能拆成一圈简单圆的运动。核心是原理，而非工程实现。

## 核心原理

每个圆由三个参数描述：

- **半径 r**：该频率分量的幅值。
- **频率 ω**（角速度，弧度/秒）：负值表示反向旋转。
- **相位 θ₀**：初始角度。

圆匀速旋转，圆心沿圆链首尾相接依次累加：

\[
\theta(t) = \theta_0 + \omega t,\qquad (x_i,\, y_i) = (x_{i-1},\, y_{i-1}) + r_i(\cos\theta_i,\ \sin\theta_i)
\]

链末端 \( (x_n, y_n) \) 即画笔位置。把各时刻的末端点连起来就是合成波形；将 y 坐标沿时间轴展开、x 坐标沿幅值轴展开，得到两条独立分量；而每个圆恰好对应波形分解出的一个频率分量——这正是傅里叶级数「用一组旋转相量之和重建信号」的几何直观。

## 运行环境

- 引擎 / 编辑器：**Cocos Creator 3.8.8**（请用同版本打开，避免升级工程）。
- 语言：TypeScript。
- 启动方式：用 Creator 打开仓库根目录（`package.json` 所在处），加载 `assets/scenes/ft.scene` 后预览（模拟器 / 浏览器）。首次打开会自动导入资源并生成 `library/`、`temp/`（已忽略，无需入库）。
